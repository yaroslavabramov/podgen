# История Podgen

Снимок прежнего приложения в Git — `71aa34a630d2e181cdc288b5a8ab39329c981c3d`. Локальная метка `archive/pre-rebuild-2026-11-05` указывает на тот же коммит. Снимок включает backend, frontend, миграции, Compose, тесты, планы v1/v2 и инструкции запуска того периода.

На этой машине прежнее приложение уже доступно в `../podgen-legacy`. В свежем клоне его можно восстановить одной командой.

```sh
git worktree add --detach ../podgen-legacy 71aa34a630d2e181cdc288b5a8ab39329c981c3d
```

Архивный README и файлы разработки находятся в этом checkout. Локальные трассы прежних экспериментов хранятся отдельно от Git. На этой машине каталоги `tmp/` и `backend/tmp/` перенесены с исходной структурой в `../podgen-archives/pre-rebuild-2026-11-05/`. Выбранные для разработки реплики доступны в [выборке из пяти сцен](../../evals/fixtures/development/legacy-writing.json) вместе с путями и SHA-256 исходных трасс. Настройки окружения, базы и загруженные материалы имеют отдельный жизненный цикл.
