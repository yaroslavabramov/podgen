# Revise the story proposal

Use the assignment, dossier, candidate and `revision_guidance` to return a complete improved proposal. Address each finding at its proper scale: wording, qualification, explanatory step, act order, promise or ending. Retain useful supported reasoning and host contributions. Keep an act's local label when its function remains the same; update affected-act references when restructuring.

Reconcile the whole route after editing: prerequisites, both sides of transitions, promise, working answer, support, host functions, ending and duration assumptions. Copy material references from the offered catalog. Check editorial requests against the available evidence.

Preserve unresolved questions and blocking status until supplied evidence or a justified change within the assignment removes the dependency. Return the full proposal, including retained parts, with `ready` when no blockers remain, or `needs_research` otherwise. Use `plan=null` if no meaningful route is supported. The new version then goes to a separate review.
