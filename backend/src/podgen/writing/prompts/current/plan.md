# Propose the story

Choose a connected route from the assignment and dossier. State the listener promise and a working answer the material supports. Explain in `route_summary` what changes the listener's initial understanding and how the steps prepare the answer. A list of topics does not supply that explanation. Propose one route, without a prescribed act count.

Specify a supported opening, each act's listener question, intended change, prerequisites, supporting cards, limits and transitions, and an ending that closes the promise. Give the assigned hosts useful work in this particular explanation. Mark illustrative situations as conditional. Copy `material_refs` from the supplied catalog; references select support, not substitute for reasoning. Use short local act labels. Do not copy source excerpts into the plan.

Estimate act and total duration as ranges with assumptions, counting the opening, transitions and ending once. Identify optional substance that can be cut without breaking the explanation. These are estimates, not measured audio.

Return the complete proposal, limitations and unresolved research questions. For each question state why it matters, affected acts, relevant offered support and whether it blocks the answer. No research tool is available. Use `status=ready` only for a complete proposal without blocking questions; use `needs_research` otherwise. If the material cannot support a meaningful route, return `plan=null` with precise blocking questions. A supported answer about uncertainty can be ready. Editorial acceptance is a separate decision.
