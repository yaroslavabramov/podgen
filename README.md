# Podgen

Цель Podgen — выпуск подкаста по теме пользователя. Сейчас можно запустить написание полного русского сценария по подготовленному досье и плану.

## Что работает

В режиме оценки Podgen загружает материалы кейса из хранилища. Автор пишет черновик, редактор получает его вместе с теми же источниками, затем автор возвращает полную редакцию. Запуск сохраняет фактические запросы, ответы, замечания и обе версии текста. Два доступных кейса — диалог про GPS и документальный рассказ о колонке на Брод-стрит.

- [Как запустить сценариста и получить тексты](backend/WRITING-EVALUATION.md)
- [Полученные сценарии, сравнение версий и результаты проверки](evals/reports/2026-11-05-writing/README.md)
- [Входные материалы двух кейсов](evals/cases/development/wp02-batch-01/README.md)

Для пути от произвольной темы до опубликованного аудио ещё требуются самостоятельное исследование, независимый фактчек и аудиопроизводство.
