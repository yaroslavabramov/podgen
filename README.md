# Podgen

Podgen производит подкаст по теме пользователя. Целевой процесс связывает исследовательское досье, работу автора, независимую проверку сценария и прослушивание готового аудио.

## Старт разработки

Текущий этап — M0. Полная спецификация и порядок работ согласованы. Первая инженерная задача — реализовать контракты и сохранение версий (WP-01). Параллельно начинается подготовка экспертных досье и оценочного корпуса (WP-02). Для проверки качества письма предусмотрен полный русский выпуск на одинаковом материале для сравниваемых авторов.
