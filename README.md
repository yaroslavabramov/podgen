# Podgen

Цель Podgen — выпуск подкаста по теме пользователя. Сценарный путь использует подготовленное досье и готовый либо самостоятельно построенный план.

## Что работает

В режиме оценки Podgen загружает материалы кейса из хранилища. Источник плана выбирается явно:

- `fixed-plan`: готовый план из материалов кейса; отдельной проверки плана в этом режиме нет.
- `own-plan`: планировщик строит план по брифу, досье и разрешённому корпусу, без готового плана. Отдельный редактор проверяет конкретного кандидата. После правки новый кандидат проходит новую проверку; автор получает только явно принятый план.

В `own-plan` блокирующий вопрос о недостающих материалах сохраняется и останавливает путь до автора. Исследователь пока не реализован, поэтому вопрос не закрывается автоматически.

Далее автор пишет черновик, редактор получает его с теми же источниками, затем автор возвращает полную редакцию. Запуск сохраняет фактические запросы, ответы, замечания и версии текста. Два доступных кейса — диалог про GPS и документальный рассказ о колонке на Брод-стрит.

Путь `own-plan` сейчас проверяется управляемыми ответами провайдера; качество реальных самостоятельно построенных планов ещё не оценено. Живой запуск на OpenAI пока заблокирован ошибкой `credit_balance_exhausted`.
