¹ Разбиение по пробельным символам, включая отдельные знаки пунктуации. ² Расчёт при 110–150 токенах/мин, не измерение аудио; цифры при произнесении разворачиваются в несколько слов. Целевое окно прослушивания — 45–75 секунд. Выход за него фиксируется по измеренной записи; текст и скорость задним числом не подгоняются.

Для конфигурации разработчика использовать только поле `fragments` из [fragments.json](fixtures/ru-documentary-v1/fragments.json). Его элементы соответствуют `Fragment` из [comparison.schema.json](../../docs/podcast-production/audio/comparison.schema.json). `direction.style` пуст. Это фрагмент конфигурации без профилей, ключей и бюджета; он сам не запускает запросы.

`episodes/` содержит полные точные сценарии, исходные RuntimeRef, hash по `artifact-jcs-v1` и привязку двух финальных keep к тому же скрипту. UUID реплик совпадают с evaluation-importer: `uuid5(script_ref.record_id, "utterance:<index>")`. Это evaluation lineage, а не новые canonical ScriptRevision/ArtifactRef или производственный аудиодопуск.

`clips/*.json` содержит точные source→reference offsets и критические слова; `clips/*.txt` — текст для сверки слухом, без заголовков и ремарок. Срезы сохраняют исходные символы; между репликами в reference-файле стоят два перевода строки. Нативный адаптер может передавать отдельные реплики или соединять их своим документированным разделителем. Реальные provider payload/hash сохраняются отдельно. Контракт `SynthesisInput` и стабильные ID учтены в `native_synthesis_input_hash`.

[План матрицы](listening/comparison-plan.json) фиксирует 20 ожидаемых ячеек; [протокол](listening/protocol.md) и [форма оценки](listening/rating.schema.json) описывают прослушивание. План не является исполняемым `ComparisonConfig`. Подключены ElevenLabs, Gemini, Inworld и Fish на бесплатных планах; после preflight доступно до 16 из 20 ячеек. MiniMax отсутствует. Только фактически доступные квоты разрешают запросы: без покупок, смен моделей и скрытого fallback. Kari/Leonid — предварительные кандидаты Eleven v4; четыре записи одного сервиса не задают постоянный объём сравнения. Победители по описаниям голосов не выбраны.

Имена исследователей дождя, дополнительные имена Apollo, дробные значения, концовки и целые выпуски перечислены в `deferred_checks` manifest. Третьего сочинённого текста нет. Для режима подачи у двух финалистов заключительный фрагмент позднее извлекается из этих же сохранённых сценариев и фиксируется отдельно.
