# Контроль локального audio reviewer

Один существующий WAV, два отдельных вызова reviewer. Новый синтез, ASR и reviewer не запускались. Это подготовленный контроль: независимое прослушивание ещё не подтвердило звучащий год и полноту фразы. Исходный сценарий не изменён.

Позднее прочитан уже завершённый независимый Fish ASR: он распознал «Апрель 1970 года.» на том же master, год локализован в 1.00–1.96 секунды. Это corroboration, не human gold; статус акустического подтверждения не изменён. Происхождение и raw segments добавлены в `manifest.json`. Чтение всех 22 фактических кандидатов и требования к interface — в `candidate-interface-review.md`.

Аудио: `tmp/audio-fidelity-controls-2026-11-12/apollo-date-v1.wav`, первые 12 секунд decoded Apollo Concierge. Вырезаны исходные PCM frames `[0, 288000)`, 24 kHz, mono, 32-bit. Никаких преобразований звука. Хеши и исходный файл — в `manifest.json`; WAV находится в локальном `tmp`, в Git не включён. Для восстановления достаточно скопировать указанный диапазон PCM в новый WAV с исходными параметрами.

1. Независимый слушатель подтверждает, что фраза «Апрель 1970 года.» полностью и разборчиво звучит в окне. При несоответствии контроль не получает статус готовности: выбрать другое окно, не исправлять сценарий под запись.
2. Передать неизменённый `evals/audio/listening/local-fidelity-review.prompt.md`, этот WAV и `reference-exact.payload.json`.
3. В отдельном контексте передать тот же prompt, тот же WAV и `reference-altered.payload.json`. Настройки модели одинаковые. Не передавать имена файлов, README, manifest или answer key модели.
4. Сопоставить результаты с закрытым `answer-key.json`, только после акустического подтверждения из шага 1.

Reference C71 дословно взята из принятого сценария: 1970. Reference C28 — отдельная контрольная копия с заменой только года на 1972. Обеим предъявляется одна искусственная ASR-гипотеза: 1971. Это не результат Fish и не производственный кандидат. Пустой `asr_segment_excerpts` означает отсутствие ASR-таймкодов, а не уверенность в локализации.

При подтверждённом звучании 1970 ожидаются C71 → `dismissed/asr_error`, C28 → `confirmed/audible_mismatch`; в обоих ответах reviewer должен указать реально услышанный 1970 в `heard_spans`. Один лишь правильный статус без подтверждения услышанными словами не засчитывается. Неразборчивость требует `inconclusive`. Остальные слова в окне — контекст, проверяется только указанная фраза.

Такой контроль проверяет минимальное различение ошибки ASR и неверной reference по одному аудио. Он не доказывает общую надёжность reviewer или сохранность всего выпуска. Искусственные поля не должны попадать в производственные ASR receipts или сохранённый сценарий.
