# Snow: отдельное испытание длинной формы

Это операторское задание для сравнения двух способов написания, а не дословный запрос пользователя. Исходный пользовательский 15-минутный бриф, пакет и его run сохранены без изменений.

[Бриф](brief.md) и [пакет](shared.json): русский язык, один рассказчик, документальный детектив для взрослого неспециалиста. Цель — 1800 секунд, допустимый диапазон 1620–1980. Центральный вопрос и порядок выбирает планировщик.

В пакет без изменений включены 16 текущих карточек Snow. Семь новых карточек добавляют факты из уже сохранённой книги Джона Сноу 1855 года: первое издание и замысел проверки, перенос водозабора Lambeth, смешанная сеть соседних домов, расследование в Кеннингтоне, квитанции и химический тест, сравнения за четыре и семь недель. [Дополнение](supplement.md) содержит только фактические записи. Каждая новая запись привязана к точным выдержкам и символьным диапазонам исходного текста. Всего в пакете 23 карточки и 52 выдержки. Часть семинедельной сводки основана на расчёте, что отражено в самой записи.

Источники D2–D4 и их SHA сохранены из исходного пакета. D1 — новый бриф. D5 — новое фактологическое дополнение. Все пять документов допускаются в один новый scope. Для D2–D4 используются прежние файлы:

- `evals/cases/development/wp02-batch-01/author/snow-pump/dossier.md`
- `evals/cases/development/wp02-batch-01/sources/snow/snow-1855.txt`
- `evals/cases/development/wp02-batch-01/sources/snow/parish-1855-b21363870.txt`

Текст Сноу — транскрипция, описанная в README первичного корпуса. Новые разделы прочитаны в этом тексте; проверка нового печатного скана не заявляется. Приходский отчёт и книга Сноу не объявляются независимыми исследованиями. Локальные C/L-идентификаторы карточек не меняют идентичность первичных источников.

Оба способа написания должны использовать один этот пакет и один план, получивший обычное решение Terra `accept`. Профили: Sol medium для планирования и написания, Terra medium для планового ревью и двух независимых чтений. Автор и редакторы получают полные штатные проекции без ручного редактирования результатов. Реальные ответы, привязки, расходы и решения записываются в отдельный отчёт сравнения.
