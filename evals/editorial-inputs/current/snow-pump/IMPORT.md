# Импорт обновлённого Snow

Из корня репозитория, с настроенным `PODGEN_DATABASE_URL` и доступом пользователя к проекту:

```sh
uv run --project backend python evals/editorial-inputs/current/snow-pump/import_case.py \
  --project "$PODGEN_PROJECT_ID" \
  --actor "$PODGEN_ACTOR_ID" \
  --objects "$PODGEN_OBJECTS_DIR" \
  --scope snow-percolation-2026-11-08 \
  --out-dir "$SNOW_WORK_DIR"
```

Команда допускает точный бриф, новое досье, полный текст книги Сноу и полный текст приходского отчёта, затем импортирует `shared.json`. Используются только штатные команды допуска, с проверкой SHA и дословных диапазонов. Вызовов моделей нет. Файлы источников перечислены в [README.md](README.md); HTML и PDF оригиналов остаются в прежнем корпусе и не переписываются.

Для воспроизведения экспериментов на пакете `b52d0f03…` передайте той же команде `--input evals/editorial-inputs/current/snow-pump/history/before-percolation-2026-11-08.json` и отдельные scope и каталог результата. Предыдущие четыре файла источников доступны по исходным путям пакета.

Результаты в `SNOW_WORK_DIR`:

- `D1-ref.json` … `D4-ref.json` — допущенные документы;
- `source-map.json` — точные связи путей с RuntimeRef;
- `shared-ref.json` — новый вход для штатного запуска.

Для нового сквозного запуска использовать `--author-ref "@$SNOW_WORK_DIR/shared-ref.json"`, `--case snow-pump`, `--plan-mode own-plan`, новый `run-id` и новую папку экспорта. У обновлённого кейса нет фиксированного плана. Выполнение моделей — отдельная команда запуска; импорт её не выполняет.

V9 передаёт только явно выбранные в `narrative_excerpt_indices` дословные атрибутированные выдержки внутри соответствующих карточек. В Snow выбрано 8 из 47: для гипотезы, осмотра, истории Фрейзера, бытовой детали и физического открытия. Планировщик выбирает из досье; автор получает карточки, выбранные планом, правщик — их и материал, адресованный фактчеком. Отсутствующий или пустой выбор означает отсутствие цитат, без возврата всех по умолчанию; GPS остаётся без изменений и использует этот безопасный fallback. Фактчек получает все первичные выдержки, холодный читатель источников не получает. Старые пакеты, ссылки, версии проекций V1–V8 и прежняя ID-миграция сохраняются для воспроизведения.
