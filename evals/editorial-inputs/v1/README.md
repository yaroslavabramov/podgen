# Редакционные входы v1

Два подготовленных назначения: `gps-clock` и `snow-pump`. Полные исходные брифы, досье, планы и первичные материалы находятся в [неизменённом корпусе](../../cases/development/wp02-batch-01/README.md).

В каждом каталоге:

- `shared.json` — назначение и смысловое досье для обеих веток. Схема: [editorial-input.v1](../../../backend/schemas/editorial-input.v1.schema.json).
- `fixed-plan.json` — отдельно структурированный первоначальный готовый план только для fixed-plan. Схема: [fixed-editorial-input.v1](../../../backend/schemas/fixed-editorial-input.v1.schema.json). Связь с shared — через digest канонического JSON, с оригиналом — через SHA-256 его точных байтов.

Карточки составлены редактором из исходных брифа, досье и первичного корпуса; прежние сгенерированные планы/финалы, эталоны и задания оценщика не использованы для их наполнения. `label` — естественное локальное имя для выбора опоры. `documents` и диапазоны выдержек служат серверной проверке происхождения, в авторскую речь не передаются.

У GPS 9 карточек: сигнал; псевдодальность; общие часы; совместное решение; геометрия; микросекунда; условные два маяка; остаточные ошибки; известная высота. Сохранены одна эпоха, определение знака сдвига, совместная оценка, требование геометрии и различие между вкладом в псевдодальность и ошибкой координат. Учебная формула и пример — редакторский синтез. Уравнение NASA на слайде 38 находится в изображении: текстовое извлечение не выдаётся за цитату формулы.

У Сноу 16 карточек разделяют решение сентября 1854 года и последующее расследование. Сохранены:

- 89 зарегистрированных за неделю смертей и 83, **произошедшие** в последние три дня;
- отрицательные/неизвестные ответы о питье; неустановленные сроки приобретения сведений о работном доме, пивоварне и доставке воды;
- смертельные приступы отдельно от смертей, 45 неизвестных дат начала, частично расчётные даты и спад до закрытия;
- поздний рассказ матери, несовпадение датировок, зависимость свидетельств, физический осмотр и оба направления спора о диагнозе;
- временное возражение Уайтхеда и позднее уточнение о небольшом количестве отходов с третьего этажа.

Выдержки выбраны по смысловым границам. Одна короткая дефиниция GPS намеренно поддерживает несколько связанных карточек; на входе ревьюера одинаковые диапазоны объединяются. У Сноу повторов полного текста выдержек нет. Два разрыва страниц разделены на отдельные точно привязанные диапазоны без изменения оригинала. OCR-ошибки внутри выбранного первичного текста не исправляются молча.

Импорт требует серверной карты допущенных источников; наличия пути/хеша в JSON недостаточно. Все полные поля сохраняются, длинное недопустимое поле вызывает явную ошибку.
