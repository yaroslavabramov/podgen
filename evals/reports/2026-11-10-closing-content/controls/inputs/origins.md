# Происхождение материалов

| Случай | Происхождение |
| --- | --- |
| Apollo | Сохранённые `plan` и `draft` выпуска `tmp/apollo-ending-choice/apollo13-air/export`. Полный черновик из 19 реплик и 1052 слов. Пакет с подлинными свидетельствами NASA: `evals/editorial-inputs/experiments/apollo13-air`. |
| Snow | Сохранённые `plan` и первый `draft` выпуска `tmp/listening-order-trial/snow-pump/export`. Пакет и тексты источников взяты из этого же сохранённого запуска. |
| Библиотека | Уже зафиксированный до этой проверки вымышленный контроль `evals/reports/2026-11-10-ending-comparison/controls/holdout`. В этой проверке получены те же бриф, досье и план. Полный произносимый текст впервые написан для данного контроля по письмам Нади и записям заведующей. |
| Поиск работы | Новый вымышленный пример, написанный для проверки. Весь исходный материал, бриф, план и полный текст размещены в `work/`. За одним откликом можно проследить от кандидата до рекрутера. |

В `script.md` приведены только произносимые слова. Для отправки используются `script.json` с оригинальными ведущими и полная версия `plan.json`. У положительных случаев `plan.md` — краткое представление этих же полей для чтения человеком. У исторических случаев воспроизведено полное штатное представление из операторского экспорта.
