# Один кандидат: три разбора для двух редакторских ролей

Прочитаны две последние итоговые реплики исследовательского чата `01a1b59f-b8ea-76b3-8473-fba1e06bc48b` и полные текущие инструкции обеих ролей. В кандидатах добавлены только три вымышленных разбора: любительский оркестр, эстафета, обмен семенами. В каждом есть предшествующий контекст, окончание, решение о нём и исполнимая правка либо её отсутствие.

- [Редактор плана, solo](plan-review-solo.md) · [diff](plan-review-solo.diff)
- [Редактор плана, dialogue](plan-review-dialogue.md) · [diff](plan-review-dialogue.diff)
- [Редактор текста](reader-review.md) · [diff](reader-review.diff)

Примеры редактора плана одинаковы в двух форматах: они оценивают выбранное содержание и поручают изменение `ending` с переходом, оставляя речь автору. У reader показаны реальные слова вымышленного сценария: сохранение общего итога, связная замена с точными границами и локальное удаление оговорки. Решения относятся только к показанному окончанию, не изображают полную рецензию невидимого выпуска. Формулировки и концовки примеров не предлагаются как образец голоса будущего подкаста.

Исходные инструкции сохранены побайтно как префикс каждого кандидата. Размер добавлений и хеши исходников, кандидатов и добавлений — в [manifest.json](manifest.json). Production, схемы, модели и остальные файлы не изменялись. API и общие тесты не запускались.

## Спорные места для проверки

1. В reader по-прежнему есть требование вырезать комментарий, который повторяет уже понятное и ослабляет темп. Его можно снова применить к допустимому общему итогу, объявив тот менее живым. По замыслу этой проверки правило сохранено; первый пример показывает другое применение. Эффект примера ещё не проверен.
2. В положительном примере обобщение связывает концерт с обычными неделями музыкантов. Эту функцию можно назвать новым взглядом и тем самым неверно потребовать такой же добавки от любого допустимого итога. В решении явно разрешено, что и мысль уже понятна; новый факт или новый взгляд не служат основанием для допуска.
3. По последнему уточнению координатора отрицательное окончание содержит четыре связных предложения: перед общим выводом они заново объясняют передачу палочки, потерю времени, ускорение и удержание темпа. Контекст показывает, что эти действия и причинные связи уже развиты. План заказывает тот же проход как обоснование вывода, без прямой команды повторить. Общая мысль сохранена как допустимая; претензия относится к пути через уже разобранные этапы. Более короткие перечисления могут работать: ни имена, ни количество слов сами по себе дефектом не названы. Перенос различия на другие случаи ещё не проверен.
4. В примере оговорки контекст явно исключает обещание урожая. Это основание для конкретного удаления, не разрешение убирать необходимые ограничения в других рассказах. Живая часть сохранена целиком, но из примера не следует обязанность всегда заканчивать действием или предметами.

Дальше нужны независимые чтения неизменных входов с заменой только соответствующих инструкций. Ни результатов этих чтений, ни допуска кандидата пока нет.
