# Закроет ли другой редактор пропущенную правку

**В этом сравнении причин менять Terra на Sol нет.** В новом черновике о Сноу после двух способов проверить удалённые адреса идут четыре числа из разбивки смертей. Ни одна модель не поручила сократить этот блок. Sol обязательной сочла только грамматику фразы «Было ли у девочки холерой»; устранение непрозрачной отсылки к способу удаления отходов оставила на усмотрение автора. Terra потребовала также поправить описание стока, чтобы не изображать его трубой, которая вела прямо в колодец. [Первый отзыв Terra](../fresh-snow/reviews/reader-review.json) · [Первый отзыв Sol](fresh-snow/output.json)

На истории о Райтах Sol предложила запись без исправлений. Terra предложила точнее сказать об управлении рулём. Обе сохранили ход четырёх полётов, второе появление фотографа и финал с телеграммой. [Решение Sol](wright/output.json) · [Решение Terra](../wright/output.json)
