# Доприсерч: восстановление и локальный переразбор

Исправлены пункты 1 и 4 аудита от 21 ноября. Платных вызовов нет.

## Владение и сохранность

Первое ролевое задание определяет смысл поручения. Операционные повторы сохраняют нативную беседу и доказательства всех попыток. `reading_audit/evidence`, проверка сохранённой рецензии и чтение поручения автору используют это происхождение. Для durable source recovery сохраняется проверка разрешения и точного запроса отказавшего физического шага. Строгий `request_payload` по-прежнему отклоняет два пользовательских сообщения.

Два штатных локальных цикла с PostgreSQL проверяют доприсерч → отказ по кредитам → разрешённый повтор → сохранение → следующую рецензию → открытие готового результата. Проверены фактчек и `revise-1`. В фактчеке доказательства до и после отказа сохраняют разные идентификаторы физических попыток. Повтор готового цикла не вызывает провайдера и не повторяет получение документов.

## Разбор Gemini

Принимается один JSON, при необходимости в Markdown fence, с необязательным библиографическим приложением `Sources`. Номера ссылок могут начинаться с 11 и иметь пропуски. Второй JSON, посторонняя проза и дубли ключей отклоняются. Библиография не подтверждает цитату: каждая выдержка сравнивается с неизменяемым текстом сохранённого документа буквально.

Приложение из 40 ссылок взято без изменения из сохранённого отчёта `tmp/hieroglyphs-30m-script-2026-11-15/targeted-research-export/report.md`. Его отдельная тестовая копия: `backend/tests/fixtures/gemini_deep_research_sources.md`, SHA-256 `7f22afe10918156e0328492675190069961da6a6a106acd1594790b9843e0834`. Исторический отчёт был обычным текстом; JSON-объект в проверках создан локально и обёрнут этим реальным приложением.

При смешении точной и ложной цитаты точная сохраняется отдельно. Весь ответ остаётся `unresolved`, неподтверждённый ответ помечен `unverified_answer`, отклонённые ссылки перечислены по индексам. Недоступный документ также не уничтожает остальные пригодные выдержки. Частичный отчёт не допускается как завершённый.

Старый сохранённый `unresolved` может быть переразобран локально под ключом новой версии. Исходные запрос, ответ, результат ошибки и ссылки остаются неизменными. Переразбор читает завершённый дочерний отчёт непосредственно, без `prepare`/`advance` hosted research. Новый результат и ссылка на исходный результат находятся в одной неизменяемой записи. Проверен обрыв сразу после её публикации и повтор без новой работы. Прежний успешный результат возвращается точно как сохранён.
