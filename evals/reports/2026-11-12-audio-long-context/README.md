# Проверка более длинного контекста

25 секунд вместо 3,4. В первой стадии изменились только аудиоданные; во второй — только сохранённая расшифровка. Модель, инструкции и настройки прежние. Нового TTS нет.

Результат не улучшился. Blind-расшифровка: «Он сам признавал, что под микроскопом его не распознать и судить о нем можно только потому, что оно делает.» Сравниватель снова вернул `differs`, объяснив это разными смысловыми конструкциями «потому» и «по тому». Отличие звучания этим не установлено.

Этот запуск не подтвердил гипотезу, что именно увеличение окна до 25 секунд устранит сбой. Одна попытка не доказывает бесполезность контекста вообще. Прослушивание этого места пользователем ещё не дало явной акустической разметки.

Первое соединение оборвалось после отправки аудио и commit, до подтверждения commit и до команды response.create. Выполнена отдельная повторная отправка с тем же запросом; исходная трасса сохранена. Два завершённых вызова стоили по usage примерно **$0.022468**; для оборванного соединения usage не получен.

Полные трассы: `tmp/audio-long-context-2026-11-12/` (оборванная загрузка) и `tmp/audio-long-context-retry-2026-11-12/` (два ответа). Здесь сохранены полные текстовые запросы и ответы, hashes аудио и трасс. Production не менялся.
