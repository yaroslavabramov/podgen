## Как работает кеш

- Для переписи стабильный блок содержит принятый план и материалы, общие для обеих версий. Изменившиеся реплики, текущие решения о композиции и новые замечания идут позже. На первой переписи Claude записывает общий префикс в кеш на пять минут. На второй может прочитать его, пока запись действует. У черновика собственная форма ответа. Новые инструкции, переход к другому виду переписи или истечение срока кеша могут потребовать новой записи. Отдельного платного прогрева в рабочем процессе нет. [Кеш Anthropic](https://platform.claude.com/docs/en/build-with-claude/prompt-caching) · [Влияние формы ответа](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)
- Внутри одного вида переписи форма ответа теперь стабильна. Конкретные разрешённые фрагменты входят в каждое задание. Перед сохранением сервер сверяет с ними каждую вставку, замену, удаление и перестановку.
- Для повторной редактуры плана Terra получает досье до проверяемого плана, для проверки фактов — доказательства до текущей версии сценария. Редактор сценария получает только свои инструкции, сведения о слушателе и текст. OpenAI кеширует до явно указанной границы. Переменный конец запроса оплачивается по обычной цене входа. [OpenAI Docs](https://developers.openai.com/api/docs/guides/prompt-caching)
- Новый запуск фиксирует способ сборки в манифесте. На архиве Сноу воспроизведены исходные тела 13 запросов основных этапов. Для новых запросов сверены значения редакционных полей, тексты выдержек, модели и инструкции. [Сверка по этапам](replay.json)
