# Apollo 13 and rain–soil writing evaluations

These two cases tested the same writing workflow on different material. Each run produced its own plan and an independent review. The writer received the accepted plan. A listener's reviewer and a factual reviewer then assessed the same script version. Each run allowed up to two script revisions.

| Case | Listener brief | Observed outcome |
| --- | --- | --- |
| Apollo 13 | A 6–8 minute documentary about carbon dioxide removal | One plan revision and two script revisions. The first rewrite corrected the air-hose direction and removed repeated explanation. The second brought the final script to 880 words. |
| Rain and soil bacteria | A 4–6 minute explanation of an observation and the experiment behind it | The first plan passed. One script revision addressed an unexplained transition from the green bacterial marker to yellow spots in the image and removed a repeated conclusion. The final script had 523 words. |

Both reviewers accepted the same final script in each case. The fixture manifests bind that script to the exact review results below. The estimated reading time for Apollo 13 was eight minutes at 110 words per minute. Neither run measured audio duration.
