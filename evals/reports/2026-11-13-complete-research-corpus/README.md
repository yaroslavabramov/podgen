# Полный исследовательский корпус: реализация и проверка

Пакет из исследовательского чата `01a1b59f-b8ea-76b3-8473-fba1e06bc48b` от 13 ноября. Литературные поручения, модели, последовательность ролей и две переписи сценария сохранены.

**Работа остановлена по просьбе пользователя. Код и текущие проверки завершены и закоммичены. Генерация не возобновлялась: есть план, первый сценарий и две рецензии; переписанного финального сценария нет.** Исправление отказа Anthropic проверено локально, но его принятие живым API не проверено. Этот отчёт не означает приёмку полного выпуска.

## Реализовано

- Автоматическая обработка всех ссылок завершённого исследования, сохранение результатов по документам и повторное использование прежних загрузок.
- Поиск по полному корпусу с пакетным построением сохраняемого индекса и страницами результатов; прежние границы 64 документа / 2 млн символов / 12 тыс. фрагментов сняты.
- `frozen-corpus-tools/7`: продолжение работы за пределами 12 вызовов модели / 24 инструментов; реальные размеры контекста модели; полные рабочие заметки, отдельное компактное состояние продолжения и доступ к истории.
- Адресная загрузка источника и передача конкретного исследовательского вопроса до завершения проверки. Незавершённая проверка не становится поручением переписать текст.
- Доступные между этапами дополнительные отчёты X, отдельные первоисточники S, сохранение их исходных ссылок при повторном использовании плана.
- Исправлена привязка дозагруженного источника к разделу отчёта при различиях URL в регистре hostname, стандартном порте или fragment. Исходные URL и ID сохраняются. Семь адресных проверок прошли.
- Для Anthropic закреплена политика строгой схемы инструментов: навигационные аргументы проверяются Podgen до исполнения, три инструмента загрузки/состояния и итоговый ответ остаются строгими у провайдера. Старые запросы сохраняют прежний режим; доказанный отказ компиляции допускает отдельную сохранённую попытку восстановления. См. [изменение и проверки](messages-grammar-fix.md).

Описание контрактов: [research-corpus-runtime.md](../../../docs/podcast-production/research-corpus-runtime.md).

## Один обычный выпуск о долготе

Использован прежний завершённый Gemini Deep Research. Новое общее исследование не запускалось. Обработаны все 62 ссылки: 20 прежних результатов переиспользованы, 42 адреса дополнительно обработаны. Читаемый текст получен для 51 источника, всего 881 277 символов. См. [corpus-summary.json](corpus-summary.json).

Запуск: `f7e9dbac-c64c-5698-807a-fa8b25e69a2f`, `production/1`, обычный полный процесс. Архив работы: `tmp/longitude-corpus-2026-11-13/`.

На 22 завершённых вызовах планировщика обнаружен квадратичный рост служебных перечитываний. Процесс остановлен между вызовами: все 22 ответа и 22 результата инструментов сохранены, запросов с неизвестным исходом нет. [runtime-diagnosis.md](runtime-diagnosis.md) объясняет причину и замер. После исправления продолжили тот же запуск; предыдущие ответы заново не генерировались.

Ускорение перенесено коммитом `94ba1332`. [runtime-fix.md](runtime-fix.md) и [runtime-benchmark.json](runtime-benchmark.json): восстановление 32,35 → 0,99 с, обращения к служебной metadata последнего хода 48,70 с / 544 170 SQL → 0 SQL. Запросы побайтово совпадают; проверки на БД включают отзыв доступа.

План и его штатная рецензия завершены: по 26 физических вызовов модели, без прежнего принудительного финала. План принят без обязательных замечаний. Сохранены [план](plan.json), [рецензия](plan-review.json) и [первый сценарий целиком](first-script.md). В первом тексте 1737 слов; это расчётный объём, аудио не генерировалось.

При первом подсчёте токенов перед автором провайдер вернул HTTP 529 (`overloaded_error`); генерация текста не отправлялась. Обычный resume продолжил тот же выпуск, не генерируя план и рецензию повторно. Автор завершил черновик за четыре физических вызова: поиск по H1, чтение S27, поиск по K1/Куку и текст.

Первое чтение выявило вещи, которые необходимо проследить через редактуру: повторный перечень достижений в финале; «океан от этого безопаснее не стал»; добавленные автором размер H4 и сравнение цены K1 с кораблём. Сам сценарий вручную не исправлялся, эти замечания не подмешивались в продуктовый прогон.

Штатный reader потребовал целиком перестроить финал и убрать повтор позиций в споре о награде. Fact после 34 физических вызовов потребовал пять локальных правок. [Редакторская рецензия](first-reader-review.md), [фактологическая рецензия](first-fact-review.md), [независимый разбор обоих решений](independent-first-readings-review.md). Четыре фактологические правки имеют предметную опору; обязательная правка фразы про трое часов выглядит ложноположительной: проверяющий добавляет к разговорному описанию гарантию безошибочности и исключает уже названные в абзаце внешние сверки. Размер H4 отдельным claim check не проверен; review не доказывает и не опровергает его точное значение.

Есть отдельная несогласованность оценки времени: план предполагает 1650–1800 слов на 13:30, тогда как действующий reader оценивает текст по 110 словам/мин. Плановая настройка `planning_duration_contract` отсутствует и в прежнем профиле; это не регрессия нового корпуса. Первый текст по продуктовой оценке — 15:48 при верхней границе 15:00. Это оценка, не измеренная запись.

Первая перепись остановлена Anthropic до получения результата: HTTP 400, `invalid_request_error`, `The compiled grammar is too large, which would cause performance issues. Simplify your tool schemas or reduce the number of strict tools.` Ошибка однозначная (`ambiguous: false`), готового ответа нет. В сохранённом native request 13 strict tools; структурная схема результата прежняя. Подсчёт токенов прошёл, но он не выполняет компиляцию схем. Это ограничение общего грамматического представления, описанное в [документации Anthropic](https://platform.claude.com/docs/en/build-with-claude/structured-outputs#schema-complexity-limits). Исправление транспорта и восстановление проверены на локальных тестах; исходный отклонённый запрос и все завершённые этапы сохранены. Живой повтор не отправлялся по просьбе пользователя.

Остались непроверенными: принятие новой грамматики провайдером, исполнение замечаний автором и качество последнего текста. Есть также измеренная локальная задержка при входе в новую роль; [разбор оставшейся повторной загрузки материалов](runtime-startup-review.md) не является готовым исправлением. Новые работы по этим пунктам не запускались.
