# Проверка фактчекера без исследовательского отчёта

**Удаление отчёта не устранило наблюдаемый сбой фактчекера.** Один новый полный проход закончен; сценарий не переписывался. Режим без отчёта остаётся отдельной проверкой, а не новым поведением production по умолчанию.

Сохранены прежний первый сценарий о долготе, профиль Terra, настройки, задание и все 51 читаемый документ. Удалены отчёт, его оглавление и пути чтения синтеза через инструменты. Старые рецензии и наши контрольные выводы модель не получала. В прежнем проходе она действительно прочитала четыре раздела отчёта — 18 133 символа.

[Полный новый ответ](../2026-11-13-fact-review-source-only/live/fact-review-output.json), [точное сравнение входов](../2026-11-13-fact-review-source-only/preflight/full-request.diff), [архив всех запросов, ответов и источников](../2026-11-13-fact-review-source-only/live/trace.tar.gz).

## Что изменилось в решениях

| Проверяемое место | Результат нового прохода |
| --- | --- |
| Пять тиков / полных колебаний H4 | Полезное уточнение сохранено. |
| «Сдал K1 в 1769 году» | Прежнее правильное замечание потеряно. Источник различает изготовление в 1769-м и предъявление/осмотр в 1770-м. |
| «Почти как небольшой корабль» | Прежнее замечание потеряно: конкретное ценовое сравнение отдельно не проверено. |
| Диапазон цены Эрншоу £65–100 | Недостаточная опора замечена. Выбор одной цены для сравнения не доказывает самостоятельную арифметическую ошибку. |
| Три хронометра | Сохранилось чрезмерное обязательное требование: практический способ проверки трактуется как обещание абсолютной безошибочности. |
| «Океан от этого безопаснее не стал» | Снова принято после замены смысла на «другие опасности сохранились». |
| Критерий Акта о долготе | Новое обоснованное уточнение: пространственный предел из Акта нельзя безусловно отождествлять с двумя минутами хода на любой широте. |
| Размер H4 — примерно 13 см | Теперь явно проверен и принят обоснованно. |

Основания и точные координаты: [независимая оценка до опыта](baseline-independent-review.md), [независимая оценка нового ответа](new-review-independent.md). Полностью прочитан ответ с audit, а не только список замечаний; 17 сохранённых доказательных срезов сверены с исходными документами.

Конкретный дефект виден в самом audit. При переводе исходных слов в `contextual_meaning` исчезает проверяемая деталь: датированная сдача превращается в изготовление вообще, сравнение цен — в общую дороговизну, отсутствие улучшения безопасности — в сохранение рисков. Одновременно практическое объяснение трёх часов усиливается до абсолютной гарантии. Все реплики отмечены проверенными, хотя часть их утверждений подменена или пропущена. Это не объясняется недоступностью соответствующих источников: нужные места прочитаны.

Один проход не устанавливает причинное влияние удаления отчёта и устойчивое преимущество режима. Он показывает, что одного изменения доступа для устранения этих ошибок недостаточно. Следующая содержательная работа — сохранность проверяемого утверждения при интерпретации и полнота решений по реально прочитанному тексту; новые поля или дополнительный этап из этого результата не следуют.

## Стоимость и оставшаяся задержка

Новый проход: 43 генерации, 42 действия инструментов, без повторов и дозагрузок. Поиск вызывался 13 раз, как прежде; чтений источников стало 18 вместо 14, страниц каталога — 11 вместо одной. Полные токены и оценка по сохранённым тарифам: [usage.json](../2026-11-13-fact-review-source-only/live/usage.json). Оценка генерации — **$0,228**, не выписка биллинга. Из 1 723 875 входных токенов 1 661 670 пришлись на кеш.

Полный замер дал **11 мин 9 с и 212 684 SQL-запроса**: подготовка 100,5 с / 100 150 SQL; проверка 512,1 с / 65 375 SQL; экспорт 56,3 с / 47 155 SQL. Внутри проверки 13 локальных поисков заняли 152 с. Пиковая память процесса — 1,21 ГБ. [Измерения и их границы](../2026-11-13-fact-review-source-only/live/run-measurements.json).

Это остающийся технический дефект; предыдущие улучшения отдельных операций не означают, что весь путь уже эффективен. Чтение кода после замера указало следующие места для отдельного измерения и исправления без новой платной генерации:

- `StreamingSearch.refresh` читает текст для определения языка, токенизации и embedding-фрагментов без общей ограниченной операции чтения. `append_batch` заново проходит авторизацию индекса. Нужно измерить эту часть отдельно от остальных действий startup.
- Экспорт по отдельности открывает события и blobs, повторяя авторизацию. Полный экспорт уже сохранён, его можно использовать для бесплатного повторяемого замера.
- Поиск передал CPU cross-encoder 2 419 кандидатов за 13 разных запросов: `candidate_pool=96` применяется к трём веткам до объединения. Это отдельная вычислительная стоимость; нельзя приписывать все 152 секунды авторизации каждого текстового среза, поскольку чтения внутри поиска уже объединены.

Агрегаты не доказывают долю каждого пути и причину пика памяти. Во время контрольного прогона эти механизмы не менялись, чтобы сохранить настройки сравнения.

## Исправления и проверки кода

Старые сохранённые результаты подсчёта токенов теперь переиспользуются после проверки привязки к точному запросу и профилю. [Проверка совместимости](../2026-11-13-engineering-audit/legacy-count-replay.md): 32 теста. Отдельный режим фактчекера, запрет обходных путей и повторное чтение готового результата без новой генерации проверены набором из 56 тестов. Эти наборы не суммируются как число уникальных тестов.

В живом проходе сохранены 43 результата count и 43 их переиспользования при отправке; повторный count для того же запроса не выполнялся. Чужие изменения сохранены. Своя копия PostgreSQL остановлена после экспорта и резервного копирования; исходная база не менялась. Дополнительных генераций после единственного законченного фактчека не запускали.
