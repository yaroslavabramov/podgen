# Парное чтение со старой инструкцией

После получения основной восьмёрки добавлены две исходные пары для проверки вклада изменения. По цене двух дополнительных вызовов проверяем ровно те предпочтения, которые особенно задевают прежние инструкции: сочинить отсутствующий финал (b) и дать высказаться ироничному рассказчику (g). Остальную матрицу второй раз не оплачиваем. До этих двух вызовов исходные оценки модели на данных текстах неизвестны.

Во всех четырёх соответствующих запросах пользовательский payload, схема, профиль и способ запуска совпадают. Оценить по прежним замороженным критериям. Если прежняя версия находит тот же ход, результат показывает сохранение способности на этом примере; преимущество нового промпта утверждать нельзя. Для b просьба только сократить или поменять уже имеющиеся слова не считается заказом композиции. Для g отмечаем отдельно сохранность шутки и конкретность аргумента.
