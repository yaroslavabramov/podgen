# Источники GPS

Оригиналы: `nasa-introduction-2017.pdf`, `sps-2020.pdf`, `faa-how-it-works.html`; неизменные полученные bytes. Даты/URL получения в acquisition JSON; дата NASA-выступления 08.06.2017, SPS — April 2020, дата публикации FAA не установлена. Каталог NTRS: `nasa-catalog.json` (PUBLIC; GOV_PUBLIC_USE_PERMITTED; containsThirdPartyMaterial false). SPS на титуле разрешает неограниченное публичное распространение; FAA — текст федерального ведомства США. Использование источников не означает одобрения NASA/FAA/DoD наших сценариев.

Прочитаны NASA 1, 25–38 (30/37/38 дополнительно визуально), SPS §2.2.2.1/§2.4.5/C-1 DOP/C-4 pseudorange+PVT/C-8 c, содержательная часть FAA полностью. Остальные страницы сохранены, но не объявлены прочитанными. Оригинальные эмблемы и иллюстрации не переносятся в модельный текст как собственные.

`*.txt` — pypdf 6.21.4 `page.extract_text()`, PDF страницы размечены с 1; FAA main извлечён BeautifulSoup 4.15.0 / html.parser / get_text с newline и strip. UTF-8 LF, без дополнительной Unicode нормализации. Формула на слайде 38 отсутствует в text extraction: проверяйте PDF и `nasa-slide-38.png`. PNG — рендер 1.5×1.5, вспомогательная копия. Оригинал PDF остаётся основанием. Извлечение не объявлено полным для всех рисунков.

[Опоры](evidence.json) содержат exact text, SHA-256, Unicode codepoint offsets `[start,end)` в `.txt`, locator. G1–G10 — локальные метки импорта, не канонические ArtifactRef и не независимые оценки. Полное объяснение происхождения и границ — в досье автора. GPS источники описывают одну систему и не образуют три независимых эксперимента над устройством.
