# Основания ключевых утверждений

Авторская модельная самопроверка, 05.11.2026. Не независимый VerificationReport, не полное извлечение всех claims. Все основания — один первичный труд, в современной транскрипции; независимость свидетельств не выдумана.

| Фрагмент финала | Основание / проверенное ограничение |
|---|---|
| «Сняли ручку восьмого сентября…» | S1: встреча Thursday, 7th September, снятие на following day; S9 прямо называет 8th. Календарная дата выводится из текста, не из даты загрузки |
| «Книга… в следующем году» | Титул HTML: 1855; в досье не перепутан с PG release 2024. Издание второе, не первая формулировка всей гипотезы |
| «Он… колебался с выводом» | S3: осмотр вечером 3 сентября и little organic impurity. Факт колебания приписан автору, не придуман мотив |
| «Восемьдесят три смерти…» | S4: last three days of week ending September 2; рамка неполной регистрации объяснена. Не все жертвы вспышки |
| 61 / 6 / 6 | S4. Это 73 случая внутри зоны колонки; отдельно рассматриваются 10 ближе к другим. Финал не называет 61/83 долей всех заболевших. Арифметика 61+6+6+10=83, расчёт по данным опроса, не оценка риска |
| Дети: двое известно / третий вероятно | S4: известное и родительское предположение сохранены раздельно |
| Встреча с советом / кто снял | S1 подтверждает авторское сообщение о причинной связи встречи и снятия; не даёт стенограммы, мотивов всех участников или имени исполнителя. Формула «в нашей подборке нет» не объявляет отсутствие протокола во всех архивах |
| Работный дом: 535 / 5 / другие приняты уже больными | S5. Пять — не ноль; дополнительное водоснабжение не объявлено единственной разницей с соседями |
| Пивоварня: >70, без тяжёлой формы, двое нездоровы | S6: исходное “at least in a severe form” и источник Хаггинс сохранены. Нет вывода о доказанной защите пивом |
| Доставка в Хэмпстед / племянница / служанка | S7, сын женщины как источник Сноу; оставлен благополучный/нетяжёлый исход служанки. Не все альтернативы исключены |
| Пропуски карты / больницы / адреса | S8; это описание Сноу, не наш аудит графики. Предъявление карты совету не установлено, а не отрицается как исторический факт |
| Условный больной с несколькими датами | Иллюстрация, прямо «представим». Различие регистрации, смерти и onset опирается на S4/S9 и с. 41/50; новый пациент не введён в историю |
| 143 на 1 сентября / 54 на 3-е | S9: именно No. of Fatal Attacks. Исходная HTML-таблица прочитана с заголовками. Не общее число заражений и не число смертей за эти даты |
| «У сорока пяти… дата… неизвестной» | S9 и объяснение на с. 50–51. Восстановление дат не названо точным наблюдением каждого onset |
| 7 сентября больше 6-го; 8-го 12 | S9: 28 > 20; 12. Отказ от ложной строго монотонной истории. Эти числа не дают эффекта снятия ручки |
| Отъезд и неопределённость состояния воды | S2: Сноу приписывает уменьшение смертности отъезду; говорит impossible to decide о состоянии воды при прекращении пользования. Его уверенность про отъезд передана как его оценка, не независимая величина эффекта |
| «Прекращение… может быть обоснованным» | Редакторская интерпретация совокупности S1–S9, явно «наш вывод». Не универсальное правило медицины, не реконструкция убеждений совета |

Скана издания не было в чтении; электронная транскрипция может содержать ошибки. Существенные числа сверены между сохранённой HTML-таблицей и извлечением, но это одна representation family. Отдельный оригинальный регистр, протокол совета и лабораторное состояние воды 8 сентября не прочитаны. Для усиления исторической квалификации нужны независимый source audit и при споре сверка скана. Число предотвращённых случаев здесь остаётся неизвестным, а не нулевым.
