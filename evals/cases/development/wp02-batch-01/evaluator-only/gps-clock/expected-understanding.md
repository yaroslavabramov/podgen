# Только оценщику: GPS

Development-разметка, созданная моделью вместе с материалами. Кандидат критериев, не gold, согласованный экспертами, и не уже полученные ответы слушателей. Не передавать автору/генератору и не включать в поиск их источников. Сначала свободный пересказ, затем вопросы без подсказок; ответы хранятся отдельно от критериев.

| Задание слушателю | Приемлемый смысл ответа | Опора |
|---|---|---|
| Как прибор получает положение с неточными часами? | Из нескольких сигналов совместно оценивает координаты и общий сдвиг своих часов, имея данные о спутниках; не обязан сначала точно синхронизировать свои часы | G1/G2/G6 |
| Что в этой задаче означает четвёртый спутник? | Ещё одно независимое ограничение для четырёх неизвестных; не специальный передатчик поправки личных часов | G1/G2/G6 |
| Что показывает пример дорожки? | Лишняя сумма выявляет общий аддитивный сдвиг: 7+5−10=2, две прибавки по 1, исправленные расстояния 6 и 4; важно условие «между концами» | Учебный вывод из G2 |
| Что означает микросекунда? | Около 300 м общего вклада в псевдодальности. Не обязательно 300 м сдвига координат | G7/G8 |
| Почему после вычисления времени могут оставаться ошибки? | Общая временная поправка не описывает разные задержки/отражения; качество сигналов и геометрия важны | G2/G7/G9 |

Transfer, новый пример после свободного ответа: «Только один из четырёх сигналов прошёл лишний путь из-за отражения. Можно ли исправить его, вычитая эту длину из всех четырёх измерений?» Смысл: нет; это не общая ошибка часов, такой приём испортит другие наблюдения. Достаточно словесного объяснения. Не требовать термина multipath.

Опасные выводы: атомные часы внутри каждого телефона; четвёртый спутник знает ошибку конкретного прибора; любые четыре сигнала всегда дают точное место; каждый спутник имеет отдельную неизвестную, исправляемую одной общей поправкой; координаты уже правильно найдены тремя, потом добавлено время; два маяка достаточны для обычной трёхмерной задачи.

Диалог: содержательный вклад Ильи проверяется по обменам с дорожкой, перестановкой номера спутника, изменением места и отражённым сигналом. Не оценивать по доле слов или количеству вопросов. Возможен другой удачный обмен, если он доказуемо двигает понимание.

Рабочая шкала 0–4 — из 04: 0 неверный центральный ответ; 1 отдельные факты; 2 ответ назван, потерян механизм/оговорка; 3 ответ, связи и существенные пределы восстановлены; 4 корректно применено к новому примеру. Конкретные пороги частоты, non-inferiority margin и допустимый разрыв с профессионалом ещё не калиброваны. Не делать M1 pass по двум этим текстам.
