# Основания ключевых утверждений

Проверка автором-моделью после письма, 05.11.2026; НЕ независимый VerificationReport. Охвачены ключевые утверждения и связки, а не заявлено каноническое полное coverage. Независимые извлечение claims и omission audit ещё нужны.

| Место финала (точная начальная фраза) | Основание и результат самопроверки |
|---|---|
| «А радиосигнал за это время…» | G8: c = 299792458 м/с. Расчёт 299792458 × 0.000001 = 299.792458 м; округление «примерно 300». Рядом Илья спрашивает о координатах; Нина говорит, что это вклад в дальность |
| «Он умеет находить сразу две вещи…» | G1, G6: 3 координаты + offset. «Две вещи» — две категории ответа, не две скалярные неизвестные; позже все четыре названы |
| «Приёмник создаёт локальную копию…» | G4; слайды N1 35–37 прочитаны; 37 просмотрен визуально. Код не представлен единственной полной временной меткой |
| «Это настоящее измерение…» | G5: определение псевдодальности; G2: уравнение с b/спутниковыми/атмосферными частями. Формулу N1 слайд 38 сверили визуально с оригиналом |
| «Для наблюдений, приведённых к одному моменту…» | G2: общая δt, индексированные спутниковые члены. Модельный вывод из уравнения с явно названным условием эпохи, не универсальность всех аппаратных ошибок |
| Дорожка 10 / 7 / 5 | Синтетический пример: 7+5−10=2; 2/2=1; 7−1=6; 5−1=4; 6+4=10. Явно задано нахождение между концами и одна аддитивная ошибка. Не реальное измерение, не доказательство достаточности двух спутников GPS |
| «В обычном решении положение и время ищутся совместно» | G1/G2/G6. NASA уравнение оставляет r и δt искомыми; G6 говорит solve for coordinates and offset. Пересказ FAA о четвёртом не превращён в отдельный вид спутника |
| «Если спутники видны с полезно разных направлений…» | Геометрическая интерпретация G2 + G7; это различимость функций расстояния, а не обещание глобальной единственности всех решений. Следующий обмен прямо ограничивает устойчивость |
| «И положение берут для момента передачи сигнала» | N1 30, FAA G10: location of satellite when signal was sent. Движение не превращено в новый количественный расчёт |
| «А у разных спутников свои часы» | N1 26/30/38, G3: спутниковые поправки отдельно от приёмной. Идеальность часов не утверждается |
| «Радиосигнал… отражённым…» | G2, G9. Отражение от стены — условная иллюстрация multipath, не личный опыт ведущего |
| «Известная высота…» | G6, включая второе предложение. Условие дополнительного знания звучит; не все морские приборы объявлены одинаковыми |
| «Спутники передают сигналы, приёмник принимает…» | N1 30/35, FAA G10: широковещательная процедура. Нет заявления, что телефон никогда ничем не передаёт свою позицию |

Оставшиеся ограничения: точность конкретного телефона, смешение разных GNSS, неоднозначности первого захвата и алгоритм фильтрации не исследованы. Нет внешнего эксперимента над приёмником. Для центрального ответа пробела в выбранной идеализированной модели не обнаружено; независимая проверка может выявить дефекты. Никаких оценок слушателя или допусков этот файл не создаёт.
