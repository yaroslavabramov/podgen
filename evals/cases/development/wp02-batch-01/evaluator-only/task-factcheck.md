# Задание независимой проверки фактов

Роль — проверяющий, не соавтор. Получите закреплённый сценарий, бриф, разрешённые originals/representations и evidence-кандидаты. Не читайте авторскую самопроверку до своего извлечения утверждений. Ожидаемые ответы оценщика не являются доказательствами. Для слепого editorial first read используется отдельное задание; этот доступ не совместим с ним.

1. Пройдите все произносимые реплики по порядку, включая фактические предпосылки вопросов и связки разных спикеров. Отдельно проверьте причинность, числа, даты, атрибуции и отрицания. Отметьте полное покрытие или конкретно непрочитанную часть.
2. Извлеките утверждения собственным проходом. Затем сопоставьте с авторскими кандидатными ссылками. Отдельный omission audit должен искать пропущенный смысл, а не только проверять заполненность списка.
3. Откройте первичные фрагменты с окружением. Псевдодальность сверяется с формулой на изображении NASA 38; text extraction её пропустил. Таблица Сноу сверяется с исходным HTML и заголовками, при существенном споре — с печатным сканом, которого в подборке нет. Нельзя назвать HTML и извлечённый из него текст независимыми подтверждениями.
4. Различите supported / supported_with_limits / contradicted / insufficient / not_verifiable. Это рабочие категории спецификации, а не запись в её канонический контракт. Для ограничения покажите точную реплику, где оно слышно. Для неизвестного объясните, это нехватка корпуса или неизвестность мира.
5. Пересчитайте арифметику. Для GPS различите общий вклад c·b и ошибку позиции. Для Сноу различите рамки регистрации, onset смертельных случаев и даты смерти, проверьте неизвестные даты.
6. Ищите не только отдельные неверные фразы, но и ложный общий итог: будто четвёртый спутник специально ставит часы; будто закрытие колонки доказанно остановило вспышку. Приведите именно текст и опору.
7. Сохраните результат с хешем сценария, ID реплик, использованными источниками/локаторами, диапазоном прочитанного, наблюдаемым дефектом и необходимым результатом исправления. Для новой версии нужен новый отчёт; не переносите допуск автоматически.

На оба case нужны минимум два независимо назначенных проверяющих/редактора по исходной политике 04; независимость обеспечивается отдельным заданием и закрытым контекстом. Существенное расхождение разбирается по оригиналам. Текущий комплект не содержит выполненного независимого отчёта или AcceptanceRecord.
