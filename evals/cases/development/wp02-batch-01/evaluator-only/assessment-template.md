# Пустая форма наблюдения

Форма не является выполненной оценкой. Заполнять только после реального назначения/чтения/слушания; отсутствующие измерения — null/«не проводилось», не ноль.

- Назначение и анонимный участник:
- Роль и происхождение: человек / модель (точный профиль, если известен):
- Анонимный label, hash текста или записи (controller binding хранится отдельно):
- Режим: text first read / source audit / editorial review / full comprehension / voluntary interest / pairwise:
- Доступные входы и что фактически прочитано; нарушение слепоты:
- Prefix records: through ID, understood, open questions, first break ID/null, last clear ID, strengths; время сохранения до выдачи следующего окна:
- Итог до раскрытия: вопрос/ответ, связи своими словами, ограничения, незакрытые обещания:
- Разрешение поздним текстом: ссылка на исходное наблюдение, resolved/unresolved, ID:
- Первый потерянный переход/интерес: место, причина; prefix/retrospective:
- Существенные факты: assertion → точная реплика → source/locator → verdict → оговорка в речи → необходимый результат правки:
- Dialogue exchange / результат пробного удаления:
- Ratings 0–4 с основаниями либо abstain и причина:
- Если была реальная запись: checksum, sample rate, frames, реально прослушанные ranges, full/partial и пропуски:
- Voluntary outcome/последний frame/собственная причина; prior interest/familiarity; причина цензурирования:
- Если сравнивались варианты: порядок, предпочтение/tie/abstain, rationale (отдельное задание):
- completed_at и независимость от автора/других оценщиков:

Пока реальных заполнений нет, коллекции человеческих оценок, читок и слушательских результатов пусты. Нельзя заполнить эту форму вымышленным участником для демонстрации метрик.
