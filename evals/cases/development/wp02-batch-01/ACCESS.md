# Правила доступа

Это development-корпус. Закрытая область нужна для независимости проверки, хотя её материалы в этом checkout доступны оператору. Название `evaluator-only` само по себе **не обеспечивает ACL**. Генератор с полным доступом к репозиторию не является изолированным участником; такой запуск помечается contaminated и не идёт в слепое сравнение.

| Роль | Разрешённая выдача | Закрыто |
|---|---|---|
| Автор / генератор / профессиональный контроль | Только выбранные brief+dossier+plan и sources соответствующего case через `export-author` | Оба сохранённых сценария, правки, source-check, expected answers, сценарии сравнений, результаты других участников, общий каталог этой партии |
| Независимый первый читатель, фаза 1 | `task.md`, только назначенные реплики `spoken.txt`, собственные неизменяемые наблюдения | Бриф, заголовки актов, досье, план, citations, происхождение, этап draft/final, прошлые reviews, ожидаемые ответы, будущие окна при prefix-режиме |
| Тот же редактор, фаза 2 | Только после финальной записи первого чтения — brief/plan/dossier, источники и текущие наблюдения | Ответы другого оценщика до самостоятельного решения; новая версия требует нового слепого чтения |
| Независимый фактчекер | Назначенный script+brief, frozen sources, candidate evidence; авторские привязки после собственного извлечения claims | Положительная самооценка как исходная истина; чужой verdict до своего отчёта; запрещённый внешний scope |
| Слушатель понимания / свободного интереса | Одна назначенная нейтральная запись и соответствующее задание | Другие варианты темы, текст, досье, ответы, авторство, план |
| Организатор / adjudicator | Всё в этой development-партии, назначения, ответы | Calibration/holdout без отдельного полномочия |

В production-интеграции эти границы действуют на read tools, manifest resolution, retrieval, previews, prompt cache, trace, файлы и экспорт. Общий индекс не строится по `evaluator-only`. Ожидаемые ответы и их метаданные не проходят closure автора через ссылки из EvaluationCase. Импортёр выдаёт генератору safe projection разрешённых inputs, а не полный EvaluationCase. Удаление закрытого материала распространяется на копии/экспорты/cache; редакционная правка этого не отменяет.

Экспортный помощник копирует по фиксированному allowlist; author-export не содержит даже имён закрытых файлов. Это проверяемое средство упаковки, а не реализация backend ACL. Получатели работают в отдельных сессиях с доступом только к выданной папке. Настоящее прохождение AC-17 потребует WP-01/06 и negative access tests.

Первая партия уже прочитана и создана этой модельной сессией. Она не может выступить независимым слепым оценщиком своих же текстов. Исправление этого ограничения требует новой изолированной роли/назначения, а не переименования файла отчёта.
